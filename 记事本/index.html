记事本 · 快捷键与说明

一个完全运行在浏览器本地的纯文本编辑器，没有任何服务器与账号。
Ctrl + S下载为 .txt 文件
Ctrl + O打开本地 txt / md / json 等文本文件
Ctrl + N新建（会先保存当前内容）
Ctrl + F查找与替换
Ctrl + D插入当前日期时间
Ctrl + Shift + C复制全部内容
Ctrl + A全选（浏览器原生）
Tab / Shift + Tab缩进 / 反缩进选中行
F11专注模式（隐藏所有工具栏）
Esc退出专注模式 / 关闭查找栏
数据存在哪？浏览器 localStorage
正文、文件名、字体字号与主题偏好都会自动保存到当前浏览器的本地存储， 刷新、关闭浏览器再打开都不丢失。但清除浏览器数据、使用无痕窗口、 或换一个浏览器 / 换一个域名打开，内容不会跟随——重要内容请用 Ctrl + S 导出成文件保存。

新建文档

清空编辑器开始新文档。当前内容已自动保存过，但仍建议先导出留档。
